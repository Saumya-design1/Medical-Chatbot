# 🩺 Medical AI Chatbot (RAG Engine)

A Retrieval-Augmented Generation (RAG) medical assistant built with **Flask**, **LangChain**, **Pinecone**, and **Groq (Llama 3)**.

## 🛠️ Tech Stack
- **Backend**: Python 3.11, Flask
- **Orchestration**: LangChain
- **Vector DB**: Pinecone
- **LLM**: Groq API
- **Embeddings**: HuggingFace (`sentence-transformers/all-MiniLM-L6-v2`)
- **Frontend**: HTML5, Tailwind CSS, jQuery
